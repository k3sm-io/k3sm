# Design documents

This directory holds the design documents for significant changes to k3sm, as
GOVERNANCE.md requires. Each one states the problem, the scope, the threat
model where one applies, and the decisions taken, and it is reviewed by pull
request before the implementation it describes lands. `docs/DESIGN.md` remains
the overall architecture; a document here records one subsystem's design in
more detail than that page can.

Current documents: [keystore.md](keystore.md) and [release-index.md](release-index.md).

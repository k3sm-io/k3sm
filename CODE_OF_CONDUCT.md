# Code of Conduct

The k3sm project has adopted the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
(version 2.1) as its Code of Conduct. We expect all participants — contributors,
maintainers, and users — to abide by it.

## Reporting

Report unacceptable behavior to the maintainer
**[@kitsumiko](https://github.com/kitsumiko)** on GitHub. Reports are handled
confidentially.
